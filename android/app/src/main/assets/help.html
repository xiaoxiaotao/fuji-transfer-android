连接你的富士相机

方式一：蓝牙启动 Wi-Fi

适用于需要蓝牙唤醒传图热点的机型。X-E5 固件 1.12 已由用户验证此流程可浏览和保存照片。

  1. 关闭 XApp，开启相机蓝牙。首次连接时进入“蓝牙/智能手机设置 → 配对注册”。
  2. 点击首页“蓝牙启动 Wi-Fi”，允许附近设备权限，选择相机并确认配对。
  3. 允许系统连接相机 Wi-Fi；提示无法上网时保持连接。完成后自动进入图库。

若安全握手反复失败，可以删除手机和相机两端的旧配对记录，重新注册。长按蓝牙按钮可复制诊断。

方式二：直连相机 Wi-Fi

适用于相机能手动开启“无线通信/图像传输”热点的机型。X-E5 自固件 1.10 删除了旧“无线通信”菜单，目前未确认 1.12 有独立开启传图热点的入口，请继续使用蓝牙方式。

  1. 在相机开启无线传图，并停留在等待连接画面。
  2. 手机系统 Wi-Fi 设置连接相机显示的热点，回到首页点击“直连相机 Wi-Fi”。
  3. 确认相机 IP 地址（默认 192.168.0.1），保留“自动识别”，点击“连接当前 Wi-Fi”。相机提示确认时按 MENU/OK。
  4. 也可在直连窗口填写相机 Wi-Fi 名称、密码，点击“选择相机 Wi-Fi”，通过系统弹窗连接。密码不会保存。

自动识别依据相机返回的协议能力，其他机型仍需实测。识别不合适时，可重连并手动选择“旧款无线通信”或“新版 XApp 连接”。相机连接家中路由器的设置，不能代替传图热点。

浏览与保存

点击图库右上“选择”，或长按一张照片进入多选。逐张勾选任意数量，也可全选或清空。底部“下载 N 张”仅下载已选照片，成功保存后移出选择，失败与未下载项目保留。点击“停止”会在当前文件完成后停止剩余任务。下载时保持应用打开、相机开机。

进入图库后点击照片查看，使用下载按钮保存到手机。首次传图建议先尝试一张 JPEG；RAW、视频和不同机型的支持程度需分别验证。手机图库可在 Fudge 相册中找到已保存照片。

USB 连接

  1. 相机选择“USB 读卡器”连接模式，确保 USB 通信开启。
  2. 用支持数据传输的 USB-C 线连接相机和手机，开启相机。
  3. 点击首页“USB 连接”，允许访问 USB 设备。此路径尚需真机验证。

局域网发现

用于支持电脑自动保存、无线联机拍摄等局域网模式的相机，不是蓝牙扫描。普通相机传图热点请使用上面两种方式。

下载任务与记录

图库底部“下载任务”可查看等待、下载中、保存中、成功、失败和已停止项目。当前连接中可一键重试失败项或继续已停止项；点击停止会先完成当前文件。关闭任务窗口不会停止下载。首页“下载记录”可查看手机上的历史记录。重新连接后请在图库重新选择照片，历史任务的旧编号不会直接重用。此版本不支持后台下载服务或断点续传。

反馈问题

提供相机型号与固件、手机 Android/HyperOS 版本、连接方式和完整诊断，有助于适配其他机型。避免提供 Wi-Fi 密码。
