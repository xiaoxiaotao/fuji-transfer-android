# zh.66 富士原图参数识别

日期：2026-10-12。分支：codex/android；版本：0.2.3-zh.66-film-recognition，versionCode 78。

## 流程

原图 → 编辑器「参数」 → 原图识别胶片模拟 → 展开详情 → 保存为个人配方 → 确认表单 → 离线查看 / 分享文字 / 制作配方签。识别参数不修改照片颜色，不写相机。拍摄卡的识别值始终来源于当前照片，手动备注是独立字段；批量任务分别读每张原图。

## 解析与来源

自实现有界 JPEG APP1 / Exif TIFF / ExifIFD / 0x927C MakerNote 读取。只读取 JPEG 扫描数据之前的段，最大扫描头部 2 MiB，单段最多约 64 KiB，不解码像素、不搜索压缩数据中的签名。TIFF 支持两种端序；富士目录按小端读取，所有间接偏移限制在其所属 TIFF / MakerNote 边界内，目录最多 512 项，损坏文件不阻止正常预览。后台运行，不添加解析库依赖。

字段枚举与单位参考官方 [ExifTool FujiFilm.pm](https://github.com/exiftool/exiftool/blob/2200871d9cef988051d2a99d67df3bda6cbb30a8/lib/Image/ExifTool/FujiFilm.pm)。没有复制或加入该库代码；只实现所需格式和标签映射。FilmMode 0x1401 读取彩色模拟；Saturation 0x1003 中的 Monochrome / Acros / Sepia 优先，避免误标为 Provia。高光、阴影使用有符号原值 -value/16，保留半档；清晰度 value/1000。

白平衡偏移保留原始值，明确提示原始单位，暂不统一除以 20：机型间标度存在差异，本轮两张 X-E5 原图均为零偏移，无法验证非零步数换算。动态范围显示已有标签的文字，缺失百分比不会编造。未知枚举只显示标签号和原值，不保存为已知设置。

## 来源保留

配方记录附带 detected 原始字段快照。当前字段与快照相同则标原图识别，修改则标个人记录；机型从普通 EXIF Model 读取，也保留来源。名称默认「模拟名 · 原图记录」，属于生成的可改名称。缺失字段留空，不推断自定义配方名称、槽位、参考曝光或网络配方身份。
