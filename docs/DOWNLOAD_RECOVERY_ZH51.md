# zh.51：断线状态与未完成下载恢复

开发分支：`codex/connection-download-recovery`。真机验证通过后合并 main。

- 跟踪实际用于相机的 Android Network，网络丢失时统一显示 Wi-Fi 断开、停止下载并保留记录；其他网络变化不触发相机断线。主动断开先清除监听身份。
- 下载前保存整批照片的相机身份和照片指纹；任务数据库从 v1 无损升级至 v2。
- 重新连接同一台已配对相机，在下载任务页点击“恢复上次未完成下载”，核对当前照片后创建新会话任务，使用当前照片编号。
- 已保存文件继续使用现有保存凭据跳过。中断的单个文件从头下载，不是按字节续传。
- 未找到、身份不完整或重复身份的照片不会自动下载，历史记录保留。旧版本任务没有照片指纹，需要重新选择。Wi-Fi 直连及 USB 没有可靠相机身份时不开放跨会话恢复。
- 核对过程中中断会保留原清单。启动新服务前设置恢复模式，避免服务提前执行普通下载。

真机验收：选择多张照片开始下载，中断连接，再连接同一相机；验证断线提示、任务保留、恢复后文件完整且没有重复保存。再检查正常断开重连、停止剩余、取消恢复及应用重启后的清单。
