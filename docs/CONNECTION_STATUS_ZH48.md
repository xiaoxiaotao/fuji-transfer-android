# zh.48 连接状态展示

相机页和图库页共享连接状态卡，四个阶段分别显示：蓝牙、Wi-Fi、相机会话、图库。文字与颜色同时表明等待、连接中、已连接、重试中、错误、已断开；Wi-Fi 直连无需蓝牙，USB 无需蓝牙和 Wi-Fi。

只有安全配对验证完成才显示蓝牙已连接；相机热点取得网络地址后显示 Wi-Fi 已连接。TCP 成功只代表网络通路建立，此时相机会话仍显示连接中；会话及照片索引完成后才显示图库可用。失败后的错误说明会保留，直到用户再次主动连接。

若蓝牙在已建立的 Wi-Fi 图库会话中单独断开，卡片会显示蓝牙已断开，并注明 Wi-Fi 传图连接仍有效，不把整条会话误报为断开。手动断开先显示关闭中，下载中则说明等待当前照片保存，网络释放后显示已断开。断开及错误状态会拒绝迟到的成功事件。

状态来自连接回调、Wi-Fi 地址就绪、会话建立、索引完成等明确事件。PTP 初始化与恢复通过可选的 native 进度回调传递，不从日志文字推断状态。后台 BLE 待机与前台图库连接仍是不同流程。

图库卡片点击可查看相机信息，长按可复制诊断。关闭窗口或离开页面后停止该卡片的刷新。小屏手机使用较紧凑的字号与间距；图库正常就绪时省去重复的文件数量说明，照片数量仍显示在图库标题区。

回归验证覆盖：TCP 成功不提前宣称图库就绪；蓝牙单独断开；迟到事件不能覆盖手动关闭/错误；Wi-Fi 与 USB 的非必要步骤；新连接清除旧错误；协议恢复显示进行中；两页状态卡渲染及文字完整性。原有小屏照片可视区域检查继续保留。

验证结果：72 项 Android 测试全部通过，失败/错误/跳过均为 0；8 项 native 恢复场景通过。assembleDebug 和 lintDebug 通过，Lint 仍有 241 条警告。已检查连接中、错误、已断开、图库可用及小屏的渲染图。

安装包版本为 0.2.3-zh.48-connection-status / versionCode 60。沿用原签名、通过签名校验，已在处于断开状态的小米 10 Pro 覆盖安装并启动；实机界面确认四阶段卡片正常显示。完整连接流程的实机状态切换仍需后续验证。
